Cape Town Pilot

Starting With Real Demand, Not Assumptions

Pool Up is beginning with selected Cape Town work corridors.

Routes are activated according to commuter demand, shift times, driver availability, vehicle suitability and verification.

Proposed First Corridor

Muizenberg to Airport Industria

We are collecting registrations from:

  • People travelling to work in Airport Industria
  • Drivers already travelling along the route
  • Employers with staff travelling from the southern suburbs
  • Community organisations supporting workers along the corridor

This is a proposed pilot route.

It becomes active only once the required number of commuters and a suitable verified transport option are available.

Pool Up V1 Booking Process

  1. Register through the website or WhatsApp
  2. Complete the required verification
  3. Receive a possible route match
  4. Review the driver, meeting point and price
  5. Add prepaid ride credit
  6. Receive booking confirmation
  7. Complete and rate the journey

What the Pilot Is Not

Pool Up V1 is not an instant on-demand taxi service.

It is not designed for random leisure trips.

It does not guarantee that every requested route will be immediately available.

It is a structured work-route matching pilot built around regular commuting demand.
